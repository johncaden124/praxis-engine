# Drones

Your drone scripts. Edit them here in VS Code or in the game's built-in IDE — it is the same folder.

| Script | Challenge | Unlocks |
|---|---|---|
| `c1_loops.py` | Sequential & Loops | 5x5 grid |
| `c2_csv.py` | CSV & Descriptive Stats | benchmark `s1_csv` |
| `c3_graph.py` | Weak Ties graph traversal | Graph Pathfinder |
| `c4_numpy.py` | NumPy gradient descent | benchmark `s2_numpy` |
| `c5_schelling.py` | Schelling ABM | benchmark `s3_abm` |
| `free_play.py` | sandbox (`free`) | — |

Run one: `learn run-drone c1_loops.py c1_loops` (or **Run & Commit** in the game).
Passing solutions are committed with git automatically.
