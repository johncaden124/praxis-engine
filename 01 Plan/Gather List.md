# Gather List

Everything to install, sign up for, borrow, or buy — grouped by when you need it. Items with an ID in parentheses are wired into the Godot Tech Tree via `curriculum_manifest.yaml` (checking them unlocks drone upgrades). Check items with `learn benchmark <id>` or in Obsidian.

## Before you start

### Software
- [ ] (`g_python`) Python 3.11+ (`brew install python`)
- [ ] (`g_git`) git + a GitHub account
- [ ] (`g_vscode`) VS Code (with Python + Jupyter extensions)
- [ ] (`g_obsidian`) Obsidian (open `~/Learning` as the vault)
- [ ] (`g_obsidian_plugins`) Obsidian plugins: Dataview, Templater, QuickAdd, Spaced Repetition, Periodic Notes
- [ ] (`g_anki`) Anki (optional — Obsidian Spaced Repetition works without it)
- [ ] (`g_godot`) Godot 4.3+ (`brew install --cask godot`)
- [ ] (`g_typst`) typst (`brew install typst`) for résumé PDFs
- [ ] (`g_zotero`) Zotero for citations

### Accounts
- [ ] (`g_acct_github`) GitHub
- [ ] (`g_acct_edx`) edX (CS50x, MITx)
- [ ] (`g_acct_coursera`) Coursera
- [ ] (`g_acct_khan`) Khan Academy
- [ ] (`g_acct_library`) Public library card + Libby app
- [ ] (`g_acct_kaggle`) Kaggle

### Physical
- [ ] (`g_notebook`) A paper notebook for proofs and problem sets
- [ ] (`g_timer`) A physical timer (or use the in-game Study Sanctum)
