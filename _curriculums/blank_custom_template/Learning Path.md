# Learning Path — My Custom Curriculum

> **How to use this template.** Replace everything below with your own plan, keeping the checkbox format
> `- [ ] (`id`) description` for anything you want the game to track. Then mirror those lines into
> `benchmarks.md` and wire rewards in `curriculum_manifest.yaml`. Run `learn doctor` to validate.
> Or let AI draft it: `learn init-curriculum my_plan --generate "your goal"`.

## Mission

## Stage 1: Foundations

What you study, which resources, what you produce.

**Stage 1 Benchmarks** — concrete, testable, "from a blank page".
- [ ] (`s1_first`) Describe the first thing you'll be able to do without help.
- [ ] (`s1_csv`) Write a Python script from a blank file that loads a CSV and plots something from it.

## Stage 2: Building Capacity

- [ ] (`s2_numpy`) Implement linear regression from scratch in NumPy.
- [ ] (`s2_second`) Describe a harder thing you'll be able to do.

## Stage 3: Depth

- [ ] (`s3_abm`) Build a working simulation and explain what emerged.
- [ ] (`s3_capstone`) Your capstone project or paper.

## Credentials

- [ ] (`cred_first`) A certificate, exam or public artifact.
