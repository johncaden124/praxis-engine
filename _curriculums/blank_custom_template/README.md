# Cartridge: Blank Custom Template

A minimal, valid cartridge to copy for any major or self-study goal.

1. `cp -r _curriculums/blank_custom_template _curriculums/my_plan`
2. Edit the four files (keep the `- [ ] (`id`) text` format).
3. `learn init-curriculum my_plan` then `learn doctor`.

Or generate one: `learn init-curriculum my_plan --generate "Become a data journalist in 2 years"`.
