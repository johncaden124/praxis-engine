# Learning Path — Full-Stack AI Engineer

## Mission

Go from "can write Python scripts" to shipping production LLM applications end to end: a typed backend, a modern frontend, retrieval and evaluation pipelines, and the operational discipline to run them. Theory is learned *in service of* things you ship.

## Stage 1 (Months 0–4): Engineering Foundations

- **Coding:** Python typing, testing (pytest), packaging; Git workflows; SQL (PostgreSQL); HTTP & REST with FastAPI.
- **Frontend:** HTML/CSS fundamentals, TypeScript, React basics.
- **Math:** Khan Academy linear algebra & probability refresh.
- **Reading:** *The Pragmatic Programmer*; *A Philosophy of Software Design* (Ousterhout).
- **Writing:** Weekly build-log post.

**Stage 1 Benchmarks**
- [ ] (`s1_api`) Build and deploy a FastAPI service with a Postgres database and tests.
- [ ] (`s1_frontend`) Build a React + TypeScript frontend that talks to your API.
- [ ] (`s1_git`) Use branches, PRs and code review on a real repository.
- [ ] (`s1_csv`) Write a Python script from a blank file that loads a CSV and plots something from it.

## Stage 2 (Months 4–10): Machine Learning & LLM Fundamentals

- **Coding:** NumPy, pandas, scikit-learn; PyTorch basics; Hugging Face Transformers.
- **Courses:** fast.ai Practical Deep Learning; Andrej Karpathy — *Neural Networks: Zero to Hero*.
- **LLMs:** Prompting, tool use, structured outputs, embeddings, retrieval-augmented generation.
- **Reading:** *Designing Machine Learning Systems* (Chip Huyen).

**Stage 2 Benchmarks**
- [ ] (`s2_numpy`) Implement linear regression and a small neural network from scratch in NumPy.
- [ ] (`s2_rag`) Ship a RAG app over your own documents with citations.
- [ ] (`s2_eval`) Build an evaluation harness that scores an LLM feature on 50+ test cases.
- [ ] (`s2_agent`) Build a tool-using agent that completes a multi-step task reliably.

## Stage 3 (Months 10–18): Production & Scale

- **Ops:** Docker, CI/CD, observability, cost & latency budgets, caching.
- **Systems:** Queues, background jobs, vector databases, auth.
- **Reading:** *Designing Data-Intensive Applications* (Kleppmann).

**Stage 3 Benchmarks**
- [ ] (`s3_prod`) Run an AI feature in production with monitoring, evals in CI, and a rollback plan.
- [ ] (`s3_abm`) Build a simulation (agent-based or otherwise) and explain its emergent behaviour.
- [ ] (`s3_oss`) Get a pull request merged into an open-source AI project.
- [ ] (`s3_writeup`) Publish a technical deep-dive that other engineers share.

## Stage 4: Mastery

- [ ] (`s4_ship`) Something you built is used by strangers.
