# Gather List

## Before you start

### Software
- [ ] (`g_python`) Python 3.11+ and `uv` or `pip`
- [ ] (`g_node`) Node.js LTS + pnpm
- [ ] (`g_docker`) Docker Desktop
- [ ] (`g_vscode`) VS Code
- [ ] (`g_postgres`) PostgreSQL (`brew install postgresql`)
- [ ] (`g_godot`) Godot 4.3+

### Accounts
- [ ] (`g_acct_github`) GitHub
- [ ] (`g_acct_cloud`) A cloud account (AWS / GCP / Fly.io)
- [ ] (`g_acct_llm`) An LLM API key

## Stage 1

### Courses
- [ ] (`g_fastapi`) FastAPI official tutorial
- [ ] (`g_ts`) TypeScript handbook
- [ ] (`g_react`) react.dev Learn section

### Books
- [ ] (`g_pragprog`) *The Pragmatic Programmer*
- [ ] (`g_ousterhout`) *A Philosophy of Software Design*
